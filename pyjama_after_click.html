About The Opportunity

  • We are seeking a skilled Full-Stack Developer to lead the architecture of our modern web application, ensuring seamless responsive design, SEO optimization where necessary, and clean integration with a scalable Node.js backend. The role demands deep expertise in building high-performance web applications using React and Expo, with a focus on production-grade delivery.

Role & Responsibilities

  • Design and build highly responsive, fast-loading web applications using React and Expo.
  • Implement clean page navigation, deep linking, and server-side layouts using Expo Router.
  • Build, scale, and maintain secure RESTful or GraphQL APIs using Node.js (Express, NestJS, or Fastify).
  • Optimize web bundle sizes, asset delivery, lazy loading, and rendering performance for an excellent desktop and mobile browser experience.
  • Manage client-side state (Zustand, Redux Toolkit, or TanStack Query) and write efficient queries for relational or non-relational databases.
  • Configure web deployment pipelines (Vercel, AWS, or Netlify) alongside Expo Application Services (EAS) for web builds.

Skills & Qualifications

Must-Have

  • 3+ years of professional full-stack development experience, with a heavy emphasis on React and Web standards.
  • Hands-on experience building and deploying web platforms using Expo, Expo Router, and EAS Web Build.
  • Strong backend experience using Node.js and TypeScript, including handling authentication, middleware, and database integrations.
  • Expert knowledge of modern CSS-in-JS solutions tailored for universal apps (such as NativeWind/Tailwind, Tamagui, or StyleSheet).
  • Proficient with Webpack/Metro bundlers, Git workflows, and deploying Node.js applications into cloud environments.

Preferred

  • Experience shipping a Universal App where the same Expo codebase serves both the Web App and App Store/Play Store binaries.
  • Deep knowledge of server-side rendering (SSR) considerations within the Expo ecosystem.
  • Experience with automated end-to-end web testing tools like Playwright or Cypress.
